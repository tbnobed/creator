Step 1: Story
- Title field, summary textarea, "Upload a script instead" (accept .txt, .fdx, .pdf; store the file and extract the text).
- Length picker shown as three cards: Short (about 10 min), Episode (about 30 min), Feature (about 90 min).
- On Continue, parse the script or summary into scenes (number, title, location, time of day, characters present). 

Step 2: Characters
- Grid of character cards: portrait, name, short description, and a green "Look locked" badge.
- An "Add a character" card opens an inline creation panel:
  - Name input.
  - "Describe them" prompt textarea.
  - Quick-add chips (age, hair, build, eye colour, clothing style, personality) that append "label: " to the prompt.
  - A Generate button, disabled while the prompt is empty.
  - Generate sends the prompt to the image ComfyUI workflow and returns four portrait options in a 4-up grid with "Generating…" placeholders while it runs. Use job polling or SSE.
  - Clicking an option selects it (highlighted border). Also offer "Generate again" and "Cancel".
  - "Keep this look" saves the character. It stores the chosen image as the identity reference, then generates a reference sheet in the background: front, three-quarter and profile views, plus a few expressions. Use the same identity-preserving workflow as the scene generation (character reference image + fixed seed). Store the seed, the workflow ID and the reference images on the character record.
- Clicking an existing card opens it for editing: rename, edit the description, regenerate (with a warning that scenes already created with this character will be flagged for re-render).

Step 3: Wardrobe
- One row per character, showing their outfits as cards (image, outfit name, the scenes it applies to, e.g. "Scenes 19–33").
- Add an outfit by prompt. The outfit image is generated on the locked character.
- Outfits can carry a state change from a given scene onward (e.g. "torn sleeve from scene 27", "wet").

Step 4: Scenes (places)
- Cards for each location: image, name, "Used in N scenes", and time-of-day/weather variant pills.
- Add a place by prompt. Generate a wide establishing reference image, and store it with its seed so every scene reuses that set.
- Add variants (morning, evening, night, storm), each generated from the base location reference.

Step 5: Create
- A list of the scenes, each row showing: thumbnail, title, location and time of day, a progress bar, and a status (Waiting, Creating…, Done).
- A "Create all scenes" button queues the scenes in order. Each scene's prompt is assembled automatically from the locked elements: character references, the outfit active in that scene, the location variant, plus the scene's action text. Pass the last frame of the previous shot as the init frame so scenes carry on from each other.
- Job queue

Step 6: Review
- Video player for the assembled cut, alongside a "N things to check" list.
- Each issue is a plain-language card: timecode, a description (e.g. "Eli's slicker looks dry, but he just came in from the storm"), and a "Fix it for me" button that re-queues just that shot with a correction.
- Continuity check (stub it behind an interface for now): compare each shot to the character, outfit and location references and to the previous shot, and flag mismatches.
- When there are no issues left, show "Everything matches. Ready to export." Export stitches the shots into a single MP4 with ffmpeg in the worker.
