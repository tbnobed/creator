name: OBTV logo palette
description: Brand-color decision for future OBTV interface changes
---

Keep OBTV's hot-pink-to-violet palette across new surfaces, including the gallery-first video studio. A palette change should not undo the gallery or in-place viewer interaction.

**Why:** The creator explicitly asked to return to the older palette to match the primary logo after a lime-accented studio redesign.

**How to apply:** Use the existing theme and brand variables for accents where possible; if adding bespoke gallery treatments, stay within the pink/violet and dark-neutral family rather than introducing a new signature accent.
